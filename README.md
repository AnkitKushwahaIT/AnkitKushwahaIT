## Microsoft Intune & endpoint security

- Deployed **150+ applications** through Microsoft Intune using Win32 packages and Microsoft Store apps, making them available through Company Portal.
- Configured **200+ configuration profiles** across Windows and macOS to enforce security settings through Intune.
- Configure and manage **device compliance policies** in Intune.
- Manage Windows and Apple device fleets across enrollment, configuration, application deployment, and ongoing administration.
- Configure **Microsoft Defender for Endpoint on macOS** through Intune and manage endpoint security policies.

## Apple & mobile device management
