- Administer Apple Business Manager and configure Automated Device Enrollment for corporate Mac devices.
- Deploy macOS applications using PKG/DMG packages and manage custom configuration profiles.

- Manage BYOD and app protection policies for iOS/iPadOS and Android devices.
- Configure Microsoft Defender for Endpoint on macOS and manage endpoint security policies.
- Automate Windows administration and application deployment with PowerShell.
